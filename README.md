# ProjetPersonnel
Samuel Lacombe et moi, Vann Sovannthanant, on a pensé à créer un Pokedex comme projet de session. Le Pokedex contient trois pages: index, pokedex et creation.

Index est juste une page d'accueil avec des paragraphes, on trouvait ça laid d'arriver directement dans le Pokedex comme ça.

Pokedex contient les Pokemons a affichées et qui seront inspecter par l'utilisateur, il peut aussi les effacer du Pokedex.

Création permet à l'utilisateur de créer ses propres Pokemons qui seront ensuite afficher dans le Pokedex.
